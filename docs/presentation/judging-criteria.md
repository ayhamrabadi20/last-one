# معايير الصور وخطة عرض Mustanad Jo

أرقام الشرائح في هذا الدليل تخص العرض النهائي `Mustanad-Jo-Final.pptx`، الذي يضم 17 شريحة؛ خطة ترتيبه ووقته في [speaker-notes.md](speaker-notes.md).

الصور المرفقة هي مرجع الأوزان والتوقيت الحالي. فكرة Mustanad Jo كما هي، ولا نغيّر الكود لملاءمة العرض. توثيق معايير PDF السابقة موجود في [competition-criteria.md](../competition-criteria.md) كمرجع مستقل.

| المعيار في الصورة | الوزن | ما نعرضه من مشروعنا | الشرائح الأساسية |
|---|---:|---|---|
| Impact on Jordan — الأثر على الأردن | 25% | مشكلة البداية لصاحب المشروع، العربية، أثر متوقع وطريقة قياس لاحقة | 2–3 |
| Innovation & Creativity — الابتكار والإبداع | 20% | قواعد وتوضيح وRAG ومتابعة في تجربة واحدة، دون ادعاء ابتكار التقنية نفسها | 4، 8، 15 |
| Feasibility & Scalability — التنفيذ والتوسع | 20% | MVP وتشغيل مستقل وفهارس وحدود التوسع المعروفة | 9، 12، 16–17 |
| Technical Implementation — التنفيذ التقني | 15% | المعمارية وAI والبيانات والأمان والاختبارات | 8–13 |

الأوزان مجموعها 100%. العرض والديمو **7 دقائق**، والأسئلة **3 دقائق** كما يظهر في الصورة الثانية. لا يلزم تقسيم زمن الشرح بنفس نسب الأوزان؛ يجب أن تظهر الأدلة المهمة بوضوح.

## زوايا أعضاء اللجنة

- **Domain:** هل نحل مشكلة حقيقية في المجال؟ اشرح صاحب المشروع والخطوة التي يحتاجها وحدود المحتوى الرسمي.
- **Technical:** هل AI سليم وهل يعمل مباشرة؟ ميّز تشغيل Ollama الحقيقي عن القواعد وFallback، واشرح RAG والعزل والحفظ.
- **Business:** هل سيستخدمه الناس وهل يستمر؟ اشرح سبب العودة، ثم تجربة سوقية مقترحة؛ لا تنسب للمشروع إيرادات أو شراكات غير موجودة.

الصورة الثالثة تسمح بفكرتكم الخاصة، وتطلب الانطلاق من المشكلة والبقاء قريبًا من المجال وتحديد نطاق يمكن تنفيذه. جزء من سطر قواعد البيانات محجوب؛ لا ننسخ نصًا كاملًا غير مقروء. في عرضنا نستخدم مصادر عامة ولقطات ديمو، ولا نعرض أسرارًا أو بيانات حسابات حقيقية.

## المصطلحات التي يجب فهمها

| المصطلح | شرح سهل للمتحدث |
|---|---|
| MVP | نسخة أولية تؤدي وظيفة أساسية فعلًا |
| Frontend / Backend / API | واجهة المستخدم / الخادم / نقطة اتصال الطلب بالخادم |
| Rules Engine | محرك شروط يحدد الخطوات بحسب الحالة |
| RAG | استرجاع مقاطع ثم توليد شرح يعتمد عليها |
| BM25 | طريقة ترتيب نصية لاختيار المقاطع المناسبة؛ ليست نموذج توليد |
| Ollama / LLM | أداة تشغيل نموذج لغة محلي / نموذج اللغة |
| Zod | التحقق من شكل البيانات والعقود |
| Collection / Document | مجموعة MongoDB / سجل داخلها |
| 1:N / Reference | سجل واحد له سجلات متعددة / حقل يربط منطقيًا بسجل آخر |
| Unique Index / Upsert | منع مفتاح مكرر / إدراج إن لم يوجد أو تحديث إن وجد |
| Session / RBAC | جلسة دخول / صلاحيات بحسب الدور |
| Fallback | مسار بديل معلن عند تعذر النموذج |

خطة الوقت ونصوص الشرح وأسئلة اللجنة في [speaker-notes.md](speaker-notes.md). أسماء الأعضاء وتوزيع الكلام تُضاف حسب الفريق الفعلي.
