### Backlog مرتب بطريقة MoSCoW

الأولوية هنا تفسير لقيمة MVP الحالي، وليست ادعاءً بسجل Sprint قديم. «لاحقًا» لا يعني إضافة ميزة ضمن هذه المهمة.

| الأولوية | البنود | الحالة |
|---|---|---|
| Must | الدخول والحفظ؛ فهم المدخل؛ رحلة بالقواعد؛ عرض المصدر؛ رفض نقص الأدلة؛ تعليمات تشغيل | موجود |
| Should | خطط المجالات؛ السجل دون تكرار؛ الملف والدعم؛ الإدارة؛ تجربة الهاتف | موجود |
| Could | المظهر الليلي/النهاري؛ الصياغة التفسيرية بالنموذج المحلي | موجود؛ النموذج اختياري |
| خارج MVP الحالي | بريد إنتاجي؛ اعتماد محتوى رسمي؛ قياسات حمل؛ تشغيل موزع | غير منفذ / يحتاج عملًا مستقلًا |

### افتراضات معلنة

- الجمهور عربي، والتشغيل الحالي عرض محلي؛ لم يُقَس حجم الطلب أو التوفير المالي ميدانيًا.
- المعرفة الرسمية مسودة pending؛ بيانات الإنتاج المعتمدة فارغة.
- لا توجد علاقة حكومية أو تنفيذ معاملات، ولا رفع وثائق أو دفع.
- MongoDB متاح للحسابات والحفظ؛ Ollama اختياري على الجهاز نفسه.
- لوحة الإدارة تقرأ قاعدة الجهاز الذي يشغّل المشروع، وليست بيانات جهاز المطوّر.
- أسماء أعضاء الفريق وتوزيع العمل التاريخي لم تُقدّم؛ لا نختلقها.
