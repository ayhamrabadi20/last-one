# تنظيم العمل ومسؤوليات العرض

هذه لوحة مراجعة للنسخة الحالية وتوزيع **مقترح** للشرح. لم تُزوّد أسماء الفريق أو محاضر Sprint؛ لا تمثل اللوحة سجلًا تاريخيًا مفترضًا، ولا تثبت أن العمل تم خلال مدة المسابقة.

## Kanban عند إعداد التسليم

| جاهز وموجود | ملفات التسليم الجاهزة | متبقٍ على الفريق |
|---|---|---|
| الحسابات وMongoDB والجلسات | README ودليل جهاز اللجنة | إدخال أسماء الفريق الحقيقية في شريحة الغلاف إذا لزم |
| المدخل والرحلة والاستكشاف وRAG | PPTX وPDF وملاحظات المتحدث | مراجعة توافق مدة العرض مع تعليمات اللجنة |
| السجل والقوائم والملف والدعم | التحقق من الملفات والروابط | تجربة جهاز ثانٍ / قاعدة فارغة مستقلة |
| لوحة الإدارة والمظهران | حزمة المصدر والتوثيق | نشر GitHub وإرسال رابط المستودع والعرض |

ملفات التوثيق والعرض اكتملت، وفُحصت الروابط وتنسيق الشرائح وأوامر الإعداد على قاعدة مؤقتة منفصلة. التشغيل الكامل على جهاز ثانٍ والخطوات الخارجية تبقى متبقية حتى تنفيذها فعليًا.

## توزيع مسؤوليات مقترح

| المسؤولية | ما يجب فهمه | دليل الإنجاز / الشرح |
|---|---|---|
| المنتج وتجربة المستخدم | المشكلة، الجمهور، النطاق وقصص المستخدم | شرح رحلة المستخدم والديمو |
| الواجهة | RTL، الاستجابة، حالات الانتظار والخطأ والمظهر | الواجهة ونتائج مراجعة المتصفح |
| الخلفية والبيانات | الحسابات والجلسات والحفظ والدعم وصلاحيات المدير | التصميم والفهارس والعزل |
| AI والمعرفة | القواعد، BM25، Ollama، التحقق وحدود المصادر | تتبع السؤال من الاسترجاع إلى الجواب |
| الجودة والتسليم | الاختبارات، README، القرارات وملفات العرض | التشغيل على جهاز آخر وقائمة التسليم |

يمكن دمج المسؤوليات بحسب أعضاء الفريق؛ تُسند لأسماء حقيقية بواسطة الفريق. كل عضو ينبغي أن يستطيع شرح التدفق الكامل، لا جزئه فقط.

## تتبع التقدّم ومعيار الاكتمال

المهمة جاهزة حين يظهر السلوك في النسخة الحالية، ويوجد دليل مناسب من اختبار أو فحص، ويتوافق وصفها في الوثائق مع الواقع. لا يكفي وضع علامة «منفذ» إذا كانت خدمة خارجية غير موصولة. دليل الحالة: [المتطلبات](competition-criteria.md) و[التحقق](engineering-review.md).

لتحضير المناقشة، يشرح كل عضو: لماذا تطبيق واحد؟ لماذا MongoDB؟ متى يستدعى النموذج؟ كيف يُرفض نقص الأدلة؟ ماذا يحدث للحساب المحظور؟ وما الذي لم يُنفذ؟
