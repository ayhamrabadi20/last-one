# سيناريو العرض — 3 دقائق

الخطوات التالية مثال للرحلة الأساسية. للدخول والإعداد على جهاز اللجنة راجع [README](../README.md)، وللعرض الكامل المتوافق مع معايير 5–8 راجع [ملاحظات المتحدث](presentation/speaker-notes.md).

1. افتح الصفحة الرئيسية وأشر إلى حالة Ollama: متصل أو «وضع القواعد دون AI».
2. اكتب: `بدي أفتح محل ملابس بعمّان`.
3. أجب عن الشكل القانوني بـ«مؤسسة فردية»، ثم اختر «مستأجر».
4. في الرحلة، افتح «المصدر» عند إثبات الموقع وأظهر المقطع الرسمي وحالة `بانتظار مراجعة بشرية`.
5. علّم «عقد إيجار مصدق» ولاحظ تغير نسبة التجهيز. وضّح أنها ليست موافقة حكومية.
6. اختر «تعديل الحالة»، وغيّر الهدف إلى محل مملوك؛ يجب أن يظهر سند التسجيل بدل عقد الإيجار، مع الاحتفاظ فقط بعلامات المستندات المشتركة.
7. اسأل: `كم رسوم الرخصة وكم تستغرق؟` يجب أن يمتنع النظام إذا لم يجد دليلًا كافيًا، ولا يخترع رقمًا.
8. افصل Ollama أو أوقفه ثم أعد الصفحة: يستمر الـwizard ومحرك القواعد وتظهر رسالة الوضع البديل.
9. اكتب «بدي أفتح محل حلويات بخلدا»: ينتقل التطبيق إلى مسار الاستكشاف الديناميكي ويعرض خطة غذاء/موقع مخصصة، مع تنبيه أنها خطة بحث وليست متطلبات حكومية معتمدة.

اختم: النسخة البرمجية تعمل من البداية للنهاية محليًا، أما محتوى الإجراءات فمسودة موثقة بمقاطع رسمية وتحتاج مراجعة بشرية قبل الاعتماد.
